# PrintHub 講義工單紀錄 資料字典

本文件依據正本 `Code.gs` 與 `index.html` 的實際程式碼，對照後端資料庫（`補習班講義印刷與發放數據庫` 試算表中的 `講義工單紀錄` 表）的 25 欄位整理。

### 欄位順序與定義對照（共 25 欄）

### 程式中宣告了卻無人使用（或僅讀取未呈現）的欄位
根據分析，上述 25 欄雖然均在後端宣告與讀寫，但在前端的 UI 介面與功能中並未使用到下列欄位（未在畫面上渲染）：
1. **特殊備註** (第 10 欄)
2. **到貨時間** (第 15 欄)
3. **單頁單價** (第 17 欄)
4. **特殊加價** (第 19 欄)
5. **是否完成對帳** (第 21 欄) - 雖有後端寫入功能，但前端無介面觸發。
6. **附件檔案IDs** (第 23 欄)
